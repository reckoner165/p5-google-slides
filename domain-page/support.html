Common questions

My loadImage() call fails

Most websites block other pages from loading their images, so loading an image from another site usually fails. Use an image host that allows it, or draw with p5.js shapes instead.

Inserting a GIF is slow

Large GIFs take a while to upload to the slide. The editor warns when a recording is over 5 MB. Shorten the duration, lower the frame rate, or choose a 0.5× scale to make it smaller.

"Load selected" says the image has no sketch

Only images inserted by the add-on can be loaded back, because the code is kept in the image's alt text. If the alt text was edited or cleared, the code is gone from that image.

My code disappeared

The editor keeps unsaved code in your browser's storage. Private windows, or browser settings that block site data, prevent this, so the code is lost when the dialog closes.
